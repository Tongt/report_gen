五看五定智能体使用说明

========== 方式一：在线（Streamlit Cloud）==========
1) 打开应用链接。
2) 在页面填写「你自己的」DashScope API Key 并保存；侧栏「API Key」可更换。不会在 Streamlit Secrets 里读共享 Key。
3) 上传资料、生成报告。注意：云上存储可能不持久，重启后可能要重新填 Key、重新上传。

========== 方式二：本地运行 ==========
1) 安装 Python 3.9+（建议 3.11）。
2) 终端进入项目目录：
   python3 -m venv .venv
   macOS/Linux: source .venv/bin/activate
   Windows: .venv\Scripts\activate
   pip install -r requirements.txt
3) 启动：
   streamlit run app.py
4) 浏览器打开 http://localhost:8501（以终端提示为准）。
5) 首次使用在网页填写并保存 DashScope API Key，或在本项目根目录用 .env 配置 DASHSCOPE_API_KEY（参考 .env.example）。

========== 文件位置（本地）==========
上传资料：knowledge_base/raw_uploads/
生成报告：outputs/
向量库：knowledge_base/chroma_db/
